## 🗂️ Contents

This directory contains the former root `base.yaml`, Phase 0/0+, source/observation, and source/observation-downstream configurations. Their tensor contracts, model types, run groups, and checkpoint paths belong to superseded implementations.

Relative `_base_` references are preserved within this directory. Historical config loading should name the archive path explicitly; these files are not searched as fallbacks for active physiology-semantic configs.

## 🛡️ Boundary

New configurations belong only under `experiments/configs/physiology_semantic_tokenizer/`. Do not inherit from a file in this archive.
