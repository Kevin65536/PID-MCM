decision evidence that still anchors reports. E0–E2/R0–R2, SSM/continuous-latent,
and LC-SPVQ development are stopped; superseded plans, diagnostics, code, configs,
tests, and local run generations were moved to the single Git-ignored archive.

not current instructions.

physical qualification, failed bilateral R2-D observability, and undetermined D1B.
