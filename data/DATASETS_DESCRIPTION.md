# Dataset description (compatibility pointer)

The maintained dataset description is
[`docs/DATASETS_DESCRIPTION.md`](../docs/DATASETS_DESCRIPTION.md). It contains
the dataset-native facts, units, and source notes used by the project.

For loader, mask, normalization, and split rules, use the active
[`docs/DATA_CONTRACT.md`](../docs/DATA_CONTRACT.md).

This path remains only for compatibility with older links. Do not maintain a
second dataset description in `data/`.
